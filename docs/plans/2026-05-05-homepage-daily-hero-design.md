# Homepage Daily Hero Design

**Goal:** Make the daily challenge the clear first action on the homepage, with leaderboard content supporting it below.

**Design:** Replace the current split hero/leaderboard layout with a full-width daily challenge hero. The hero carries the core message, live status, date, primary play CTA, secondary leaderboard CTA, and three compact facts: five questions, timed leaderboard, and guest play. Move the leaderboard preview into a separate full-width section below the hero, then keep categories as the final section.

**Testing:** Add a source-level homepage test that verifies the hero-first markers, leaderboard-below marker, and category section ordering.
